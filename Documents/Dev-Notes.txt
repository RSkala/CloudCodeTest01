* Link or Check Unity Project ID here

Can also use the Unity Hub to "Connect to Unity Cloud"

==================================
Installing Packages:
* Deployment: Interface for deploying code to Unity Cloud
* Cloud Code: Call CloudCode functions from inside the game

Window -> Package Management -> Package Manager
* Click + (plus) button in upper left corner
* Select "Install Package by technical name"
* Manually type in the Technical Name (e.g. com.x.x.x)
  OR
* Click Unity Registry
* Find the desired package by name

OR
Window -> Package Management -> Services
* This already contains the list of Unity services

Packages:
* Deployment
  * Services -> DevOps -> Deployment
  * com.unity.services.deployment
* Cloud Code
  * Services -> Content Management -> Cloud Code
  * com.unity.services.cloudcode

---------------------------------
After adding the Cloud Code services, there is a new Cloud Code section in Edit -> Preferences.

Since we are using C#, we are interested in the ".NET development environment"
* .NET Path should be:  dotnet
* This is the default, but if you wanted you could change this to the full path:
  * C:\Program Files\dotnet\dotnet.exe
